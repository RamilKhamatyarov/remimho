# Tunnel Golden Updater

`updateTunnelGoldens` is a standalone Gradle task and is not attached to `build`. It depends on a
successful `test` run. Its default mode is compare-only; it never writes:

```powershell
.\gradlew.bat updateTunnelGoldens
```

The updater compares the exact candidate `.tape` and `.trace` bytes under
`build/tunnel-golden-candidates/` with the three whitelisted scenario pairs under
`src/test/resources/tunnel/golden/`. Candidate files must be generated by the real fixed-step
reducer test harness. No candidate output or physics goldens are present while that reducer is
absent; the updater therefore cannot create substitute simulation results.

Update mode additionally requires `--allow-golden-write`, an evidence properties file, a native
`aarch64` JVM, a clean Git worktree, and a manifest commit matching checked-out `HEAD`:

```properties
arch=aarch64
runnerId=github-arm64-runner-123
commitSha=<full 40-character commit SHA>
hashVectors=pass
traceParity=pass
```

```powershell
.\gradlew.bat updateTunnelGoldens -PtunnelGoldenArgs="--update --allow-golden-write --evidence artifacts/arm64-evidence.properties"
```

The updater rejects unsupported candidate names and writes only the exact `.tape`/`.trace` paths
for `zero-spin-wall-bounce`, `constant-spin-curve`, and `known-sweep-paddle-contact`. The manifest
is provenance metadata, not a cryptographic signature; review the linked CI run and artifact before
using it. Unit tests use temporary candidate directories and an injected write recorder; they do
not write to the repository's golden directory.

## Physics Gate

`physics-gate.yaml` uses JSON syntax, which is a valid YAML subset, so the existing Jackson JSON
dependency can parse it without adding a YAML library. Run the machine check with:

```powershell
.\gradlew.bat determinismGate
```

Every prerequisite must have status `pass` and an evidence pointer that resolves to a repository
file or an HTTPS URL. The command prints each row and exits nonzero while any prerequisite is
pending, blocked, or missing evidence. The current gate remains closed.
